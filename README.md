# SoK: Privacy Risks and Mitigations in Retrieval-Augmented Generation Systems

This repository contains supplemental materials for the IEEE SaTML 2026 paper: *SoK: Privacy Risks and Mitigations in Retrieval-Augmented Generation Systems*

## Repository Contents

```
SoK-RAG-Privacy/
  ├── White_Literature.md                 # List with all paper titles and links 
  of the papers included in the SLR
  ├── Grey_Literature.md                  # List with all source titles and link of the websites and videos
  ├── Relevance_Maturity_Scores.pdf       # Table with the computation of the relevance and maturity scores of each proposed privacy mitigation
  └── Systematic Literature Review - Paper Analysis.pdf    # Structured literature analysis of all the papers included in the SLR

```
